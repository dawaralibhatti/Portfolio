# Portfolio

Source for **dawar.dev**, the personal portfolio of Dawar Ali Bhatti.

The page is one descent: it starts in the Milky Way, zooms down to Earth and Pakistan, then drops through the atmosphere and the clouds. An altitude rail on the right counts down from 100 km to Rawalpindi at 508 m, and the browser tab shows the altitude too.

At the bottom, the sky matches the real time in Rawalpindi (night, dawn, day or dusk), with the Margalla Hills, Faisal Mosque and the city, whose windows light up at night. The astronaut parachutes down and plants a flag; click it to launch back to space.

## Files

- `index.html` – the page
- `css/style.css` – all styles
- `js/journey.js` – galaxy and Earth animation, nav pill, Journey auto-scroll, rocket buddy
- `js/site.js` – altitude rail, clouds, Rawalpindi time and sky, landing and relaunch, copy-email button
- `js/textures.js` – Earth and Moon textures (kept inline so the globe also renders when the file is opened straight from disk)
- `images/` – project screenshots, favicon and the link preview image (`og.jpg`)
- `fonts/` – Bricolage Grotesque (SIL Open Font License, see `fonts/OFL.txt`)

Open `index.html` in a browser to view it. It works on GitHub Pages as is.
