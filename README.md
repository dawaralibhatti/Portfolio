# Portfolio

Source for **dawar.dev**, the personal portfolio of Dawar Ali Bhatti.

A single-page site (`index.html`) with a scroll journey from the Milky Way down to Earth, an intro, an About section, a project showcase (Study+, DStream, Cinepax) and contact details. All images are embedded, so the page works on its own.

Open `index.html` in a browser to view it.
