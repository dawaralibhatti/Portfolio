# Portfolio

Source for **dawar.dev**, the personal portfolio of Dawar Ali Bhatti.

The page is one descent: it starts in the Milky Way, zooms down to Earth and Pakistan, then drops through the atmosphere. The sky behind the content brightens from night to daylight as you scroll, and an altitude rail on the right counts down from 100 km to Rawalpindi at 508 m.

## Files

- `index.html` – the page
- `css/style.css` – all styles
- `js/journey.js` – galaxy and Earth animation, nav pill, Journey auto-scroll, rocket buddy
- `js/site.js` – altitude rail and the copy-email button
- `js/textures.js` – Earth and Moon textures (kept inline so the globe also renders when the file is opened straight from disk)
- `images/` – project screenshots

Open `index.html` in a browser to view it. It works on GitHub Pages as is.
